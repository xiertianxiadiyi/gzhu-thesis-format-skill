# 广州大学毕业论文（设计）格式修正工具

基于[广州大学学生毕业论文（设计）模板(中文)]，自动修正论文格式，把格式一团乱的论文变成符合学校要求的规范样子。

## 最简单的用法（推荐）

如果你在用 Claude Code 或其他支持 skill 的 agent，直接让它帮你搞定：

> **"运行clone gzhu-thesis-format-skill](https://github.com/xiertianxiadiyi/gzhu-thesis-format-skill.git ，将其添加为 skill，然后帮我修正论文格式"**



之后你只需要把论文发给它，说一声"帮我修格式"，它就能自己跑 `formatter.py` 把论文整好。

如果你不用 AI 助手，也可以自己手动跑脚本。

## 能做什么

| 功能 | 说明 |
|------|------|
| 格式诊断 | 检查论文和模板的差异，告诉你哪里不对 |
| 格式一键修正 | 自动修改页面、字体、字号、行距、缩进、标题样式... |
| 图序表序修正 | 把 `图X.X.X` 自动改成 `图X-N`（学校要求的格式） |
| 目录生成 | 自动插入目录域代码，Word 里右键更新就行 |
| 每章分页 | 章标题前自动加分页符 |
| 标点修复 | 修中英文标点混用 |

## 快速开始

### 1. 装依赖

```bash
pip install python-docx
```

### 2. 诊断格式问题

```bash
python scripts/diagnose.py 你的论文.docx
```

输出大概长这样：

```
============================================================
  广州大学毕业论文（设计）格式诊断报告
============================================================

共检测到 319 个格式问题:

【正文缩进】共 123 处
  - 第30段 "教科书是学生们获取知识的核心途径..." 缺少首行缩进

【正文行距】共 188 处
  - 第45段 行距未设置

【页面设置】共 4 处
  - 封面页左边距: 当前2.7cm → 应为3.0cm
  - 封面页上边距: 当前2.0cm → 应为2.5cm
```

### 3. 一键修正

```bash
python scripts/formatter.py 你的论文.docx 修正后论文.docx
```

### 4. （可选）标点修复

```bash
python scripts/punctuation.py 修正后论文.docx 最终版.docx
```

## 修正了哪些格式

```
页面：A4，封面左3.0cm/右2.6cm，正文左3.2cm/右3.2cm
封面标题"本 科 毕 业 论 文（设计）"：楷体 一号 居中
封面表格：楷体 左列小二号右对齐 / 右列三号居中
"教 务 处 制"：楷体 三号 居中
论文题目：黑体 三号 居中
章标题（1 前言）：黑体 三号 居中 + 自动分页
节标题（1.1）：黑体 小四 左对齐
小节标题（1.1.1）：黑体 小四 左对齐
正文：宋体/Times New Roman 小四 1.5倍行距 首行缩进2字符
"摘要"/"关键词"标题：黑体 四号
摘要/关键词内容：宋体 小四 不加粗
ABSTRACT/KEY WORDS：Times New Roman 四号 加粗
英文摘要/关键词内容：Times New Roman 小四 不加粗
目录"目  录"：黑体 小二 居中
图题表题：宋体 五号 居中
参考文献：宋体 小四 1.5倍行距
致谢：黑体 三号 居中
页码：宋体 小五 居中
```

## 生成目录

修正后的文档会在关键词下方自动插入目录域代码。打开文件后：

1. 找到 "（请在 Word 中右键此处 → 更新域，以生成目录）"
2. 右键点击 → **更新域**
3. 选择 **更新整个目录**

## 图序表序修正说明

学校要求图序格式是"图{章号}-{该章第几张}"，但很多同学会写成"图X.X.X"（节序号格式）。formatter 会自动纠正：

| 修正前 | 修正后 |
|--------|--------|
| 图2.1.2 系统工作流程图 | 图2-1 系统工作流程图 |
| 图4.1.2 系统架构框架图 | 图4-1 系统架构框架图 |
| 表4.1.3 系统架构解析 | 表4-1 系统架构解析 |
| 图6.2.1 文档上传功能测试 | 图6-1 文档上传功能测试 |

## 注意事项

- 只支持 `.docx` 格式（不是旧版 `.doc`）
- 修之前建议先备份原文件
- 电脑上要装宋体、黑体、楷体、Times New Roman 字体才能正确显示
- 代码块（Consolas 字体）不会被修改
